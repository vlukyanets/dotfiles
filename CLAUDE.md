## Documentation

`README.md` is the main document about this repo — start there. It links
out to the detailed docs in `docs/`.

## Commit messages

- First line: brief summary in the style "Added new <feature>" or "Fixed
  errors in <filename> - now <what fixed>".
- Body: up to two paragraphs of wider explanation.
- Never add AI attribution footers (no "Co-Authored-By: Claude ..." or
  "Generated with Claude Code" lines).
